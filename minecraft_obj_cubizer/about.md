# Minecraft OBJ Cubizer / Minecraft OBJ 方块转换器

Minecraft OBJ 方块转换器可以把 Minecraft 建筑导入为可编辑的 Blockbench Java 方块模型。

## 功能

- 导入带 MTL/PNG 贴图的 Minecraft 建筑 OBJ。
- 直接导入 `.schematic`、`.schem`、`.litematic`、结构 `.nbt` 和单个 `.mca` 区域文件。
- 读取原版或资源包中的 blockstate/model JSON，支持半砖、楼梯、栅栏、石墙、按钮、火把等特殊方块。
- 按 cube 面的真实像素尺寸计算原版模型缺省 UV。
- 导入到当前 Animated Java Blueprint 时，保留已有项目的贴图尺寸、UV 模式和动画。
- 按原始 X/Y/Z 坐标范围及方块 ID 筛选导入，支持 `*` 通配符。
- 后台解压和解析 NBT，先用低细节预览检查范围，再把选区转换为可编辑 cube。
- 暂缓导入过程中的新方块绘制，避免贴图加载和收尾重复刷新全部模型。
- 大型建筑支持可关闭的批量视口绘制，保留原始 cube、UV、选择、编辑和导出数据。
- 可选合并同状态的完整方块、半砖及部分楼梯，按实际面像素裁剪并平铺纹理，支持竖向动画贴图。
- 支持自动、逐方块、空间分块、单组和动画部件分组；Animated Java 自动模式采用静态主体与指定运动部件。
- 可在预览中定义部件范围与轴心，也可把所选导入 cube 整理成动画部件。
- 可选剔除被实心邻居遮挡的面；显示分批创建进度，支持取消并回滚。
- 导出或修正带命名空间的贴图路径。
- 结构导入完成后显示退回完整方块的方块 ID、数量和原因。
- 将 OBJ、结构及合并生成的贴图按完整资源路径复制到资源包目录。
- 所有功能都位于 Blockbench 顶栏独立菜单中。
- 保持本地插件安装记录可在重启 Blockbench 后继续加载。

## 菜单

加载插件后，Blockbench 顶栏会出现：

```text
Minecraft Cubizer / Minecraft 方块转换器
```

菜单中包含 OBJ 导入、直接结构导入、结构预览、动画部件整理、建筑性能模式、两套设置和贴图导出。

建筑性能模式默认开启，至少 512 个导入 cube 时，在编辑模式中按组和材质批量绘制未选中的兼容模型。选中方块仍可原生编辑；绘画、动画模式及动画/半透明贴图保留原生渲染。UV 面板最多叠加 64 个选中元素，不修改全局设置；关闭性能模式、切换项目或卸载后恢复。

贴图来源文件夹和 Minecraft Jar/Zip 文件可以直接在导入结构弹窗和“结构导入设置”中选择。

逐方块分组会把同一个源方块生成的所有 cube 放进同一个组，组名使用该方块名字。Animated Java 自动模式把未划分部件的方块放入静态 `body` 组，独立运动的部分放入指定骨骼；其他格式仍逐方块分组。合并不会跨动画部件边界。

“预览 Minecraft 结构”最多显示 2048 个粗略实例，不创建可编辑 cube，也不显示真实模型纹理。修改范围后点击刷新，确认后再“导入选区”。动画部件加号会记录当前范围；名称和轴心可以继续修改。

从 Minecraft Jar/Zip 读取的贴图会被视为仅预览资源，保存模型时不会自动另存原版 PNG 贴图。

启用兼容方块合并后，新增的 `block/cubizer/` 平铺 PNG 是自定义资源，需要随 Java JSON 手动导出；动画 PNG 同时导出 `.mcmeta`。Animated Java 的资源包输出由该插件自身处理。

每格方块大小默认 `1`。制作动画时可设为 `16`，但这也会扩大模型坐标。最小和最大选区坐标均包含边界，筛选在移动或居中之前应用。

## 注意

直接导入不会读取箱子物品、告示牌文字、旗帜图案或自定义头颅主人等方块实体数据。

结构导入里的方块上限统计的是生成后的 Blockbench cube，不是原始 Minecraft 方块数。默认上限是 5000 个 cube。若要导出为 Java Block/Item Model，建议最终模型尽量控制在约 48 x 48 x 48 格以内。

48 格的建议只对应默认每格 1 单位的比例；Java 模型实际常见坐标范围为 -16 到 32。每格 16 单位时，对应跨度只有 3 格。

源方块处理上限单独设置，默认 1,000,000；触及读取或 cube 创建限制时会明确提示。合并、透明合并和隐藏面剔除默认关闭，要逐块编辑或拆开制作动画时建议保持关闭。透明合并会移除内部面，可能改变叠加效果。

合并只沿连续轴进行，无法精确裁剪的 UV、任意角度元素旋转等仍保留独立 cube。每帧平铺图不超过 1024 像素，动画总高度不超过 4096 像素，新增平铺图 RGBA 预算为 64 MiB。

后台解析支持取消，但仍要容纳解压后的 NBT；Blockbench 5.2.2 的受限文件接口下，JAR 会异步读取一次并缓存。最终 cube 创建、视图和编辑仍消耗主线程与显存，超大建筑建议缩小选区或拆分。

本轮实机验证使用 Blockbench 5.2.2 与 Animated Java 1.11.0。结构后台导入要求 Worker 和 DecompressionStream，不支持时会提示升级。Animated Java 当前需要 Blockbench 5.1.4 及以上、Minecraft Java 1.20.4 及以上；尚未进行游戏内导出与播放验证。
